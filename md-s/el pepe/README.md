# el pepe — archivo privado de MD grupal

Estado: **archivo privado / en construcción**.

Esta carpeta conserva capturas seleccionadas del grupo de mensajes directos `el pepe`.

## Originales

Los archivos numéricos `0.png`, `1.png`, etc. son capturas fuente y deben tratarse como **originales inmutables**. No sustituirlos por versiones comprimidas ni sobrescribirlos.

La numeración representa orden de archivo/revisión, no necesariamente garantiza continuidad absoluta entre mensajes.

## Contexto aportado por el archivista

El archivista indica que en este grupo varios participantes, incluido Jezu, realizaban burlas o insultos dirigidos a Danel / Montaña VHS.

Esto se registra como contexto aportado por la parte que conserva el archivo. La atribución concreta de mensajes, acciones e intención debe verificarse contra cada captura.

## Selección

Spam, stickers repetidos, memes sin relación y contenido repetitivo pueden quedar fuera cuando no modifiquen el sentido del intercambio. Los saltos entre capturas no deben rellenarse mediante inferencias.

Si una omisión puede cambiar:

- quién propuso algo;
- quién respondió;
- quién inició una secuencia;
- el tono o significado de una frase;
- la relación temporal entre acciones;

entonces ese tramo debe conservarse o señalarse como hueco.

## Derivados para IA

`ai/` se genera automáticamente y nunca reemplaza a los originales.

Incluye:

- `ai/optimized/` — copias WebP más ligeras;
- `ai/pages/` — varias capturas consecutivas agrupadas para revisión inicial;
- `ai/manifest.json` — hashes, dimensiones y relación entre originales y derivados;
- `ai/README.md` — instrucciones para pasar el corpus a otra IA con menos carga.

Para cualquier cita o conclusión importante, volver al PNG original.
