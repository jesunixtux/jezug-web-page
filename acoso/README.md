# Archivo interno — acoso / hostigamiento relacionado con “Jezu G”

> **Estado:** interno. No publicar sin revisión y redacción.
>
> Este directorio reúne referencias recuperadas de conversaciones anteriores, Gmail, archivos de trabajo y evidencia ya preservada en este repositorio. El objetivo es tener un índice único para denuncias de plataforma, preservación y revisión futura.

## Reglas de uso

- Separar **hecho observable**, **alegación de terceros** e **interpretación**.
- No convertir una acusación, testimonio, meme, miniatura, wiki o post en un hecho probado.
- No publicar datos personales sensibles ni datos identificatorios de menores.
- No modificar los originales de `evidence/`; este directorio funciona principalmente como índice y expediente de trabajo.
- Cuando una pieza provenga solo de un chat antiguo o de memoria contextual, marcarla como **pendiente de verificación**.
- Si una URL, video o post ya no está disponible, conservar fecha, título, captura, hash y cualquier referencia previa sin afirmar por qué desapareció.
