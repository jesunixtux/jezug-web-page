# Versiones editadas / anotadas

Las transcripciones de esta carpeta son **derivadas**.

No son una reproducción literal garantizada del audio. Toda edición debe enlazar:

- al archivo preservado en `../original/`;
- a un registro de cambios en `../changes/`;
- al video/audio original cuando exista una URL recuperada.

Cambios admisibles, siempre documentados:

- correcciones evidentes del reconocimiento automático;
- nombres propios mal reconocidos;
- puntuación y separación de hablantes;
- anonimización de menores o datos privados;
- eliminación de datos íntimos no necesarios para el argumento;
- notas editoriales claramente marcadas.

Una “corrección” no debe cambiar el sentido de una declaración. Si se desea reformular una frase dramática para un resumen, esa reformulación pertenece a un resumen/análisis, no a la transcripción literal.
